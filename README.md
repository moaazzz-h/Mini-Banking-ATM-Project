# 🏦 ATM Banking System

A console-based **ATM Banking System** developed in **C Programming** to simulate the basic operations of an Automated Teller Machine.

The project focuses on applying fundamental C programming concepts such as **functions, arrays, structures, file handling, loops, conditional statements, and input validation** in a practical banking application.

## 📌 Features

* 🔐 User authentication using account credentials
* 💰 Check account balance
* 💵 Deposit money
* 💸 Withdraw money
* 🔄 Transfer money between accounts
* 📄 View account information
* 🔑 Change PIN
* 🚪 Secure logout
* ⚠️ Input validation and error handling

## 🛠️ Technologies Used

* **C Programming**
* Structures (`struct`)
* Functions
* Arrays
* File Handling
* Loops & Conditional Statements
* Input Validation

## ⚙️ How It Works

The system starts with a login screen where the user enters their account credentials.

After successful authentication, the user can access the ATM menu and perform different banking operations:

```text
==============================
       ATM BANKING SYSTEM
==============================

1. Check Balance
2. Deposit
3. Withdraw
4. Transfer
5. Account Information
6. Change PIN
7. Logout

Enter your choice:
```

Each operation updates the user's account data accordingly.
